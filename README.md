# Аналіз затримок авіарейсів у США у 2015 році

Курсова робота з дисципліни «Мови програмування для аналізу даних».
Виконав: Барановський Петро Миколайович, група 401-ТН. Керівник: ст. викл. Гайтан О. М.

## Мета

Виявити закономірності затримок і скасувань внутрішніх авіарейсів США у 2015 році залежно від авіакомпанії, аеропорту, сезону та часу доби.

**Дослідницькі питання**

1. Які авіакомпанії та аеропорти мають найвищу частку затриманих рейсів і найбільшу середню затримку?
2. Як змінюються затримки за місяцями, днями тижня та часом доби вильоту?
3. Які причини дають найбільший внесок у загальну тривалість затримок?
4. Чи пов’язана величина затримки з дальністю польоту?
5. Де і коли скасовується найбільше рейсів і з яких причин?

## Дані

Набір **«2015 Flight Delays and Cancellations»** (U.S. Department of Transportation, Bureau of Transportation Statistics), ліцензія CC0: https://www.kaggle.com/datasets/usdot/flight-delays

| Файл | Зміст | Ключ |
|---|---|---|
| `flights.csv` (≈ 580 МБ) | один рядок – один рейс: дата, авіакомпанія, аеропорти, затримки, причини, скасування | `AIRLINE`, `ORIGIN_AIRPORT` |
| `airlines.csv` | 14 авіакомпаній | `IATA_CODE` |
| `airports.csv` | 322 аеропорти з координатами | `IATA_CODE` |

Вихідні файли **не зберігаються в репозиторії** (розмір `flights.csv` перевищує ліміт GitHub). Щоб отримати їх:

1. Увійти на Kaggle і завантажити архів за посиланням вище.
2. Розпакувати три CSV-файли в папку `data/raw/`.

## Технології

Python 3.10+, pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, Tableau Public.

## Запуск

**Локально**

```bash
pip install -r requirements.txt
jupyter notebook notebooks/analysis.ipynb
```

Далі виконати всі комірки по черзі (*Run All*). Повний набір займає в пам’яті кілька гігабайтів; на комп’ютері з 8 ГБ RAM рекомендовано закрити інші програми.

**Google Colab**

1. Відкрити `notebooks/analysis.ipynb` у Colab.
2. Створити папки `data/raw` і завантажити туди три CSV-файли (або підключити Google Drive).
3. Виконати всі комірки.
